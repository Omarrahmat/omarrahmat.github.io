# Area page write-ups

One JSON file per area page (`/fostering-agencies/<slug>/`), written by the area pages desk. The slug must match an
existing area page (see `src/lib/areas.ts`: areas with two or more services). Our own words; every fact sourced.

```json
{
  "slug": "kent",
  "updatedOn": "2026-11-02",
  "paragraphs": [
    "Two to five short paragraphs, 150 to 350 words in total: who looks after children in care locally (the council's own fostering service and the independent agencies listed below), what the council publishes about the need for carers (for example teenagers, sibling groups, parent and child), what the council pays its own carers if we have a council allowance page, and how to start (speak to two or three services, ask about training and support)."
  ],
  "sources": [{ "title": "Kent County Council: fostering", "url": "https://www.kent.gov.uk/..." }]
}
```
